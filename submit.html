Submit a Port

Know an Xbox Dev Mode app, emulator, or game port that belongs in the library? Send it our way.

What We Accept

  • Projects hosted on GitHub or GitLab with publicly available source code.
  • Free and open-source apps, emulators, frontends, game ports, media apps and utilities for Xbox Developer Mode.
  • Projects you made, or that you have permission from the developer to submit.

What We Don't Accept

  • Closed-source or paid software.
  • Anything that includes or distributes copyrighted games, ROMs, ISOs, or BIOS files.

Have This Ready

  • The project name, a one line description, and the category it belongs in.
  • A card image, 1280x720 in PNG or WebP preferably.
  • The full release asset links for each download. On the GitHub release page, right click the file and copy the link. List the main app first, then any dependencies.
  • A link to the public source code repository.
  • Credits for the developer and porter, with GitHub profile links and any donation links you'd like shown.
  • Optional: requirements, features, a setup guide link, and a tutorial video link.

How It Works

Submissions are made with a short form on GitHub, so you'll need a GitHub account. Fill it out and it opens as an issue that we review before adding the project to the library.

Submit on GitHub

Don't have a GitHub account, or have a question first? Reach us on our Discord community or through the Contact page.
